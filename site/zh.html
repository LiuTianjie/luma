把第一次部署，
分成清晰的几步。

准备 Linux 管理节点、域名和 Cloudflare DNS Token，再根据网络拓扑接入私网。

环境要求与完整安装指南
Ubuntu 22.04+ Docker / Nomad Cloudflare DNS
01

安装 CLI

先在管理节点运行。安装器会创建独立的 Python 环境。

curl -fsSL https://raw.githubusercontent.com/LiuTianjie/luma/main/scripts/install-luma.sh | sh
~/.local/bin/luma preflight
02

初始化管理节点

先按安装指南配置 DNS 凭据，再初始化控制平面。

luma bootstrap manager --domain luma.example.com
03

登录并部署应用

在可信客户端使用管理 Token 登录，通过清单或控制台部署。

luma login https://luma.example.com --token <management-token>
luma deploy service.yaml

每一步，都有据可循。
